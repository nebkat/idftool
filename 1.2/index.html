    idftool¶

    The ultimate CLI tool for interacting with Espressif devices. Built on esptool and aware of ESP-IDF partition tables.

    Install idftool with pipx

    pipx install idftool

    Installation

    Or use it in the browser

    esp-web-toolkit is the browser-based equivalent: the same tools with a UI, nothing to install.

    Open esp-web-toolkit

    Why¶

    esptool flashes at arbitrary addresses. It knows nothing of partitions or OTA, so simple jobs like flashing a new app, switching OTA slots, or pulling logs off a device mean working out offsets by hand, for every partition table you deal with. idftool does that for you.

    • Device selection

      Pick your board from a list of connected devices, or name it by MAC address. No more guessing which device is on which port.

      Choosing a device

    • Firmware flashing

      Flash to the default (factory) or next available (OTA) app partition, with no offsets to memorise.

      Flashing firmware

    • Partition-name addressing

      Read, write, erase, or hex-dump a partition by name (nvs, ota_0, storage), or a slice of one with name[start:stop].

      Partition addressing

    • Safety checks

      Everything is checked before flash is touched: data has to fit its partition, apps have to be valid images built for the connected chip, and a file name given where a partition name belongs is caught straight away.

      Partitions or files

    • Bundles and images

      Pack several partitions into one ZIP and flash them in one go, or dump and restore a whole flash image.

      Backups and releases

    • Filesystems and NVS

      Flash a directory as a FAT, littlefs, or SPIFFS image (the type comes from the partition table), or pull one off the device. Generate NVS from CSV, or change a key on a live device.

      Provisioning devices

    At a glance¶

    Run any command without -p, and idftool asks which device to use:

    $ idftool monitor

   /dev/cu.usbmodem2101          ESP USB-Serial/JTAG   b8:f8:62:49:ea:14
   /dev/cu.PL2303G-USBtoUART10   PL2303GT
   ✎ Enter a port manually…
   ↻ Refresh
   ✕ Quit

$ idftool ota build/my-app.bin
Writing 'my-app v1.2.0' to partition 'ota_0'...
Setting boot partition to 'ota_0'...

$ idftool write nvs my-nvs.bin
Writing file my-nvs.bin (size=0x4000) to partition nvs (offset=0x9000, size=0x4000)

$ idftool set-boot ota_1
Setting boot partition to 'ota_1'...

    Without -p, idftool asks which device to use. See Choosing a device.
